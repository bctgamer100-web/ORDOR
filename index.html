⚡ ตรวจ ORDER กับ Stock อัตโนมัติ
เลือกไฟล์ ORDER และ Stock แล้วระบบจะตรวจจับหัวคอลัมน์จากแถวบนสุดให้อัตโนมัติ
📌 กติกา:
• Stock SKU เดียวกันหลายแถว → รวมจำนวน Stock ทุกแถว
• ORDER SKU เดียวกันหลายแถว → รวมจำนวน ORDER ทุกแถว
• Stock ≥ ORDER → ✅ พอ
• Stock < ORDER → ⚠️ ขาด X
• ไม่พบ SKU ใน Stock หรือ Stock เป็น 0 → ❌ ไม่มี Stock
• ตำแหน่งที่มีรูปแบบ เช่น KT-001-01 จะแสดงเฉพาะ KT และรวมตำแหน่งที่ไม่ซ้ำกัน
